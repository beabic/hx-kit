# hx-kit

Codex 작업 규칙 스킬 `hx`.

| 부르는 말 | 역할 |
|---|---|
| `$hx 시작` | git · 작업 규칙 · 계획 틀 준비 |
| `$hx 나누기` | README 를 7칸으로 정리 |
| `$hx 기록` | 담당자 답 기록 |
| `$hx 설계` | 설계안 비교 · 카드 나누기 |
| `$hx 카드 N` | 계획 승인 뒤 구현 |
| `$hx 위임 N` | 서브에이전트에 맡기기 |
| `$hx 점검` | 중간 점검 |
| `$hx 커밋` | 커밋 전 검사 |
| `$hx 마무리` | README · 제출물 확인 |
| `$hx 복습` | 서술형 대비 |
| `$hx 인계` | 새 대화로 넘길 상태 정리 |
